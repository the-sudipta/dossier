# Dossier original icon

Generated with the built-in imagegen tool on 2026-09-23. The final master is
`dossier-master.png`, a genuine RGBA PNG with transparent space outside the
folder/document silhouette. This is an original mark; it does not reuse the
AIUB crest. User requested a background-less logo after the first draft.

Initial prompt: Create a premium original desktop app icon for Dossier, an
academic course folder organizer. A turquoise folder, ivory documents, a warm
gold tab, sophisticated dimensional shading, excellent small-size legibility.
No text, institutional crest, or watermark.

Final edit prompt: Remove the entire background, including the dark
rounded-square tile. Keep ONLY the turquoise folder, ivory documents, and
golden tab as an isolated freestanding object. Genuine transparent alpha
background everywhere outside the silhouette. No square backing, ground
plane, or painted checkerboard. Preserve materials and original colors;
center with clear transparent margins.

PNG, ICO, and ICNS derivatives are size/format conversions of this master.
The in-app, README, and showcase images use the same 256px PNG.
