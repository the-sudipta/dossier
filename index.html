Run on Windows

Download the executable, then double-click it. Microsoft Edge WebView2 Runtime must be installed. The app embeds its templates and needs no network.

.\dossier-windows-x64.exe
Run on Linux

Extract the archive on a desktop with GTK3 and WebKitGTK 4.1, then run:

tar -xzf dossier-linux-x64.tar.gz
chmod +x dossier
./dossier
Run on macOS

Choose your Mac architecture, unzip, and open Dossier.app. Packages are ad-hoc signed and not notarized.

open Dossier.app
